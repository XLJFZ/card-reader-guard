BEFORE YOU DOWNLOAD

你可能想问。

它负责安全弹出。
硬件供电，仍取决于读卡器本身。

能让发热的读卡器降温吗？

安全弹出后，部分设备仍然供电，因此不能保证断电或降温。如果停止后仍发热，需要拔掉读卡器，或使用支持独立断电的 USB 设备。

会不会弹出我的移动硬盘？

程序只处理你手动确认并保存的绑定。新增列表也可能出现移动硬盘，所以请核对型号、容量和盘符，确认选中的是读卡器。未绑定设备不会被自动加入。

换卡以后，还能继续使用吗？

程序主要锁定读卡器的 USB 节点，同时核对设备报告的磁盘信息。部分读卡器会报告卡的信息；换卡或换接口后若身份变化，程序会跳过，需重新确认绑定。

以后怎么修改，或添加新的读卡器？

双击程序或“管理读卡器.vbs”即可打开管理页。可以添加、修改、暂停、删除或更换绑定。管理期间暂停弹出，关闭后重新计算空闲时间。

支持所有读卡器吗？

目前支持能读取序列号、具有单一直接磁盘子设备的 USB 存储节点。部分多槽、复合设备或其他驱动拓扑暂不支持。已完成一只 USB/UASP 读卡器的实机安全弹出，尚未覆盖所有型号或多只设备同时接入的实测。

安装和升级需要注意什么？

适用于 Windows 10/11 x64，需 .NET Framework 4.8 或更新的 4.x 运行时。完整解压后运行，保留 EXE 旁的配置文件。升级前停止旧版，覆盖程序文件并保留 device.xml，即可保留已有绑定。
