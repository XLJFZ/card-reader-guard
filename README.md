# Card Reader Guard · 读卡器自动弹出

Windows 小工具：首次运行时由用户选择并确认读卡器，以后仅监测绑定设备。连续 5 分钟没有读写后，通过 Windows 安全弹出接口请求停止整只读卡器。

平时没有窗口或常驻托盘图标；弹出成功时短暂显示系统通知。没有联网、遥测或自动更新功能。

## 使用

1. 下载 Releases 中的 `CardReaderGuard-v0.1.0-win-x64.zip`，解压到长期保留且可写的本地文件夹。不要放在要弹出的卡里。
2. 插入读卡器和存储卡，双击 `CardReaderGuard.exe` 或 `启动.vbs`。
3. 在引导中核对型号、容量和盘符，选择目标设备。列表也可能包含移动硬盘，软件无法可靠地自动区分所有读卡器和硬盘盒。
4. 勾选“我确认选中的设备是要自动弹出的读卡器”，点击“确认并开始监测”，在最终确认中选择“是”。可在引导中选择是否登录后自动启动。

不确定是哪一个设备时，先拔掉读卡器并刷新，再插回并刷新，确认新增的设备。初始状态不会默认选中设备；刷新或改变选择后需要重新勾选确认。

确认完成后窗口关闭，监测在后台运行。双击 `停止.vbs` 停止，通常约 5 秒生效；双击 `启动.vbs` 恢复。更换绑定时，先停止并等待约 10 秒，再双击 `重新绑定.vbs`。运行 `移除开机启动.ps1` 可停止程序并移除本工具的登录启动项。

## 绑定范围

配置保存在程序旁的 `device.xml`。同时核对完整 USB 设备实例标识、设备报告的磁盘型号和序列号。盘符和容量仅用于引导显示，不作为绑定条件。GitHub 源码和下载包不含个人设备绑定信息。

目标是锁定读卡器的 USB 节点，但部分读卡器报告的磁盘信息可能来自存储卡。换卡或更换 USB 接口后，若标识变化，程序会跳过该设备，需要重新确认绑定。程序不会因发现新设备而自动改绑。

这些标识不是密码学身份。同型号设备若报告完全相同的 USB 标识、磁盘型号和序列号，程序无法区分。通用或重复序列号的硬件应特别核对。

## 安全弹出规则

- 每 5 秒读取目标物理磁盘的累计读写计数和当前请求队列，不扫描卡内文件。
- 发生读写、存在排队请求、设备重连、缺少计数或检查异常时，重新计算空闲时间；检查间隔超过 30 秒也重新计时，避免休眠恢复后立即弹出。
- 弹出前再次核对设备身份和计数。调用 `CM_Request_Device_EjectW` 请求安全停止；被系统拒绝时静默等待新的完整 5 分钟空闲期，不强制断开、不关闭占用程序。
- 只操作已绑定的独立 USB 存储节点，不向上寻找或停止集线器。多磁盘、多子设备、无法读取序列号等不支持的拓扑会被跳过。
- 当前 Windows 所在磁盘及本程序所在磁盘会被排除。首次引导只列出支持的外接存储候选，仍由用户确认其中哪一个是读卡器。

成功停止后，再次使用可能需要重新插拔。安全弹出不保证 USB 断电或降温；若停止后仍发热，需要物理拔掉读卡器或使用支持独立断电的 USB 设备。

## 系统与限制

面向 Windows 10/11 x64，使用 .NET Framework 4.x 和 Windows WMI。当前实机测试环境为一台 Windows 电脑、一只 USB/UASP 读卡器；没有覆盖所有型号。只有单一直接磁盘子设备且能读取序列号的 USB 存储节点可绑定，部分多槽、复合设备或其他驱动拓扑不支持。

程序以当前用户权限运行，不会主动要求管理员权限。如果系统策略禁止 WMI 或安全移除，程序会跳过并记录原因。Windows 通知关闭或免打扰可能使成功提示不可见。

`status.log` 只记录运行状态、异常和弹出结果，不记录卡内文件内容或文件名。日志超过约 256 KB 后重新记录。日志和绑定文件默认被 Git 忽略。程序目录需可写；不要将绑定文件或日志上传到公开仓库。

## 构建与检查

Windows PowerShell 中运行：

```powershell
.\build.ps1
.\test.ps1
```

使用 Windows 自带的 .NET Framework C# 编译器，不需要 NuGet 包。构建结果为 `dist/` 和便携 ZIP；下载包没有预先绑定的设备，首次启动会打开引导。

可选的实机只读检查：先停止后台程序，保持目标设备连接，再运行 `test.ps1 -DeviceConfig <本地device.xml路径>`。该检查不调用弹出接口。当前实机检查假设电脑上只有一只符合条件的外接设备，多只设备时应调整候选数量断言。

命令行：`--setup` 打开绑定引导；`--background` 按已有配置静默运行，缺少配置时退出；`--stop` 请求停止；`--probe` 只读检查绑定与活动计数，结果写入日志。`--probe` 返回 0 表示通过、2 表示失败、3 表示已有实例运行。正常启动受单实例限制。

## 验证记录

2026-11-02，在一只约 512 GB 的 USB/UASP 读卡器上完成连续 5 分钟空闲自动安全弹出，Windows 返回成功，目标设备停止，两块内置硬盘继续存在。首次绑定引导已检查设备列表、未确认时禁止绑定，以及用户最终确认后进入无窗口后台运行。

另有不调用弹出接口的检查，覆盖读写、重连、缺少基线、排队请求、监测间隔、未绑定设备及型号/序列号不符等情况。降温效果和其他硬件兼容性尚未验证。
